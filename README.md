# Mohamed Hussain — Cybersecurity Portfolio

Personal portfolio for a junior penetration tester focused on web application security, network security, and vulnerability assessment.

**Live site:** [mohamed-hussain-pentester.github.io/Mohamed-Hussain-Portfolio](https://mohamed-hussain-pentester.github.io/Mohamed-Hussain-Portfolio/)

## Portfolio

The site presents my background, technical skills, penetration-testing methodology, selected projects, security labs, write-ups, certificates, and CV. It also includes a contact form and links to my professional profiles.

## Built with

- HTML, CSS, and vanilla JavaScript
- GitHub Pages
- PDF.js for the browser-based CV viewer
- Google Fonts and Font Awesome
- FormSubmit for contact-form delivery

## Project structure

```text
├── index.html       # Portfolio home page
├── contact.html     # Contact form and profile links
├── thank-you.html   # Form submission confirmation
├── cv.html          # PDF CV viewer
├── style.css        # Site styles
├── script.js        # Site interactions
└── assets/
    ├── certificates/
    └── images/
```
