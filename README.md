## Add a certificate

1. Put the PDF inside `assets/certificates/`.
2. Example:
   `assets/certificates/DEPI.pdf`
3. Open `index.html`.
4. Find the certificate card and update the displayed name.
5. Keep `data-pdf="assets/certificates/DEPI.pdf"`.

The **View Certificate** button opens the PDF inside the website.
The **Download** button downloads the PDF.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload all files and folders.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will publish the site at:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
