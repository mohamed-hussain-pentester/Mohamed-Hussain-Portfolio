## 📜 Certificates

Certificates are stored inside:

```text
assets/certificates/
```

For example:

```text
assets/certificates/DEPI.pdf
```

Each certificate can be:

- Viewed directly from the portfolio
- Downloaded as a PDF

To add a new certificate:

1. Add the PDF to `assets/certificates/`.
2. Add the certificate card to the portfolio.
3. Set the correct PDF path in `data-pdf`.

Example:

```html
data-pdf="assets/certificates/DEPI.pdf"
```

## 🌐 GitHub Pages

The website can be hosted for free using **GitHub Pages**.

### Deployment

1. Create a public GitHub repository.
2. Upload the project files.
3. Open:

```text
Settings → Pages
```

4. Under **Build and deployment**, select:

```text
Deploy from a branch
```

5. Select:

```text
main
/
```

6. Save the settings.

GitHub will generate the website URL:

```text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```
